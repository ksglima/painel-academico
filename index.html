Matéria Avaliação Data Nota Faltam
Como funciona: esta é uma página em branco — adicione suas próprias matérias e provas nos formulários abaixo de cada aba. É um site independente que roda inteiramente no seu navegador (não depende do Claude). Suas edições ficam salvas automaticamente neste mesmo navegador, neste mesmo dispositivo — os dados não são enviados a nenhum servidor e não se misturam com os de outra pessoa que abra esta mesma página no aparelho dela. A contagem de dias até cada prova e a média do semestre se recalculam sozinhas conforme você preenche os dados.
Importante: o salvamento é local ao navegador/dispositivo onde você usa a página — se abrir em outro navegador, outro perfil ou outro aparelho, não vai enxergar as mesmas edições. Use "Exportar backup" periodicamente (gera um .json) e "Importar backup" para levar seus dados para outro lugar ou recuperar depois de limpar o navegador.
Nota: a média do semestre é a média aritmética simples das notas que você lançar nas provas — não considera pesos por avaliação. Se sua disciplina usa pesos diferentes por prova, use este número apenas como referência.
